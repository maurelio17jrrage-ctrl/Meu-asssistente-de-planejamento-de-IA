# 🎯 Meu Assistente de Planejamento com IA

Projeto final desenvolvido para a trilha **Santander - Crie seu Assistente de IA** na **DIO (Digital Innovation One)**.

## 📌 Visão Geral
Este projeto apresenta a arquitetura de um **Assistente de Planejamento Estratégico com IA** projetado para transformar qualquer objetivo (estudo, carreira ou negócio) em um plano de ação executável, adaptado à rotina real do usuário e preparado para imprevistos.

Diferente da abordagem padrão em ChatGPT/Notion, este projeto foi estruturado utilizando o **Google Gemini** (via *Gems* / *System Instructions*) e uma arquitetura **100% documentada em Markdown**, garantindo portabilidade, versionamento claro e foco em processos orientados a dados.
